# お父様向けLINE自動返信ボット

このプロジェクトは、認知症のお父様からの繰り返しの質問に対して、家族の代わりに優しく自動返答するLINEボットです。

## 構成
- **言語**: Python (Flask, line-bot-sdk)
- **ホスティング**: Render (無料プラン対応)

## 機能一覧
お父様からのメッセージに以下のキーワードが含まれていた場合、自動で返答します。

1. **おかずシリーズ** (おかず、惣菜、配達など)
   - 基準日(2025年7月22日)から4週間ごとの水曜日を計算し、次の配達日を返答します。
2. **免許証** (免許、身分証など)
   - 「身分証明書に切り替えたよ！今度会うときに渡すから安心してね」と返答。
3. **お金ない** (金欠、お金足りないなど)
   - 「毎週月曜日に1万円郵送してるよ！メモしながら1週間で計画的に使ってね」と返答。
4. **野村のカード** (野村、証券、カードなど)
   - 「野村から直接ご家族で保管してくださいとお願いされた。今度一緒に来店しようね」と返答。
5. **勝手にお金管理** (管理、なんでなど)
   - 「お医者さんの指示で家族が管理することになったんだよ。心配しないでね」と返答。
6. **喧嘩してるのか** (喧嘩、怒って、無視など)
   - 「喧嘩なんてしてないよ！仕事で忙しいから日中はLINE返せないだけだよ」と返答。
7. **お金送って** (送って、振り込みなど)
   - 「毎週月曜日に1万円送ってるよ！計画的に使ってね」と返答。
8. **支払い関係** (支払い、引き落とし、光熱費など)
   - 「自動引き落としに変更したからすべて大丈夫だよ」と返答。

※ 上記以外のメッセージには反応しません（通常の家族のLINE会話を邪魔しないため）。

## 構築・設定手順

### 1. GitHubアカウントの作成とリポジトリの準備
1. [GitHub](https://github.com/) で無料アカウントを作成します。
2. 新しいリポジトリを作成します（例: `line-bot-dad`）。
3. このフォルダ内のすべてのファイルを、作成したGitHubリポジトリにアップロード（プッシュ）します。

### 2. LINE Developersの設定 (前半)
1. [LINE Developers](https://developers.line.biz/ja/) にアクセスし、LINEアカウントでログインします。
2. 「新規プロバイダー作成」をクリックし、適当な名前（例: Family）で作成します。
3. プロバイダーの画面から「新規チャネル作成」→「Messaging API」を選択します。
4. 必要な情報（チャネル名、説明など）を入力してチャネルを作成します。
5. 作成したチャネルの **「Messaging API設定」** タブを開き、一番下の **「チャネルアクセストークン (ロングターム)」** を発行してメモしておきます。
6. **「チャネル基本設定」** タブを開き、一番下の **「チャネルシークレット」** をメモしておきます。

### 3. Renderでのデプロイ
1. [Render](https://render.com/) にアクセスし、GitHubアカウントでログイン（Sign Up）します。
2. 右上の「New +」ボタンから **「Web Service」** を選択します。
3. 「Build and deploy from a Git repository」を選択し、先ほど作成したGitHubリポジトリを連携します。
4. 以下の設定で進めます：
   - Name: 任意の名前 (例: `line-bot-dad`)
   - Region: どこでもOK (例: `Singapore` や `Oregon`)
   - Branch: `main`
   - Runtime: `Python 3`
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`
   - Instance Type: **Free** を選択
5. **「Environment Variables」**（環境変数）を開き、以下の2つを追加します：
   - Key: `LINE_CHANNEL_ACCESS_TOKEN` / Value: （先ほどメモしたアクセストークン）
   - Key: `LINE_CHANNEL_SECRET` / Value: （先ほどメモしたチャネルシークレット）
6. 「Create Web Service」をクリックします。
7. デプロイが完了すると、左上にURL（例: `https://line-bot-dad.onrender.com`）が表示されるのでメモします。

### 4. LINE Developersの設定 (後半)
1. 再度 LINE Developers の **「Messaging API設定」** タブを開きます。
2. **「Webhook URL」** に、先ほどRenderで取得したURLに `/callback` を付けたもの（例: `https://line-bot-dad.onrender.com/callback`）を入力し、更新します。
3. **「Webhookの利用」** をオンにします。
4. **「Webhook URL」** の横にある「検証」ボタンを押し、「成功」と表示されるか確認します。
5. **「LINE公式アカウント機能」** の「応答メッセージ」の「編集」をクリックし、LINE Official Account Managerに移動します。
6. そこで **「応答メッセージ」** を **オフ** に、**「Webhook」** を **オン** に設定します。

### 5. グループへの追加
1. LINE Developersの「Messaging API設定」タブにあるQRコードをスマホで読み取り、ボットを友だち追加します。
2. 家族のLINEグループに、このボットを招待します。
   ※ LINE Official Account Managerの「チャット設定」で「グループ・複数人チャットへの参加を許可する」がオンになっていることを確認してください。

## 運用上の注意点
- Renderの無料プランは、一定時間アクセスがないとスリープ状態になります。スリープからの復帰時に最初のメッセージ返答に数十秒かかることがありますが、仕様ですのでご安心ください。
- 「おかずシリーズ」の計算は2025年7月22日を基準としています。
